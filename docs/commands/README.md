# Команды приложения

Приложение `webhook-service` поддерживает подкоманды. Без указания команды выводится справка по использованию.

| Команда | Описание |
|---------|----------|
| [run](run.md) | Запуск вебхук-сервиса |
| [check](check.md) | Проверка конфигурации и доступности сервисов |

**Формат вызова:**
```bash
webhook-service <команда> [флаги]
```

Справка по флагам конкретной команды: `webhook-service <команда> -h`.
