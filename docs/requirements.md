# Требования

## Язык и версия

- **Go**: 1.22 (указано в [go.mod](../go.mod) как 1.22.2; в CI используется 1.22). Окружение сборки и тестов должно соответствовать этой версии.

## ОС и окружение

- Сборка и запуск возможны на Linux, macOS, Windows (стандартный Go toolchain).
- CI выполняется на `ubuntu-latest`.
- Для Docker-образа используется Linux (Dockerfile: `GOOS=linux`).

## Зависимости

- Зависимости Go перечислены в [go.mod](../go.mod) (например `gopkg.in/yaml.v3`). Обновление: `make tidy` или `go mod tidy`.
- Внешние сервисы: Gitea (API и webhook), Jenkins (REST API с Basic Auth). Версии не фиксируются в документации; достаточно совместимости API (webhook Pull Request с `base.ref` и `head.sha`, комментарии к issue/PR, список файлов PR, статусы коммита, Jenkins tree API для списка джоб).

## Переменные окружения

- Приложение не требует обязательных переменных окружения для работы. Конфигурация загружается из файла, путь к которому задаётся флагом `-config`.
- В Dockerfile задаётся `ENV CONFIG_FILE=/etc/webhook/config.yaml`, но исполняемый файл использует путь из аргументов командной строки в ENTRYPOINT, а не из переменной окружения.
